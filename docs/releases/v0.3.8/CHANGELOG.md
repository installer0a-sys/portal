# Changelog — Developer Console v0.3.8

## Added

- Global Developer Console overlay
- System tab
- Lifecycle tab
- Queue tab
- Cache tab
- Logs tab
- Raw JSON tab
- Auto refresh every 2.5 seconds
- Keyboard shortcuts
- Portal SDK `devConsole` namespace
- Existing Core Test button opens Developer Console

## Shortcuts

- Ctrl + Shift + D: toggle Developer Console
- Ctrl + Shift + L: open Logs
- Ctrl + Shift + Q: open Queue
- Escape: close Developer Console

## No final UI redesign

This is a developer overlay only.
Portal and App layouts are unchanged.
