# Changelog — Portal SDK v0.3.4

## Added

- Portal SDK namespace
- `Portal.defineApp()`
- App Manifest Registry
- Dynamic Portal sidebar from manifests
- Dynamic route registration from manifests
- Dashboard manifest
- App A manifest

- SDK and registry diagnostics
