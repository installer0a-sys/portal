# Changelog — Portal Event Bus v0.4.0

## Added

- Central Event Bus
- Async event dispatch
- Synchronous event dispatch
- Wildcard listeners
- One-time listeners
- Listener priority
- Event history
- Event diagnostics
- Portal SDK `events` namespace
- Event Bridge
- Event-driven toast notifications
- Event-driven cache invalidation
- App A event integration

## No UI redesign

This release changes architecture only.
Portal and App visual layout remain unchanged.
